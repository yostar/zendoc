# Change Log

All notable changes to the Zendoc extension will be documented in this file.

## [0.1.0] - 2026-02-21

### Added

- **Create Zendoc workspace** — Guided wizard to create a writing workspace with folder picker and name input
- **Welcome panel** — Webview that appears on first run (replaces easy-to-miss toast)
- **GitHub setup** — Webview to connect to GitHub: create repo, paste URL, connect. Auto-closes on success.
- **Enable Automatic Backup** — One-click GitDoc enable (workaround for GitDoc startup timing bug)
- **Set up cloud backup** — Retry GitHub setup if skipped or failed
- **Show Zendoc welcome** — Manually open the welcome panel (Cmd+Shift+P)
- Template workspace with Welcome.md, settings, extensions, and Cursor rules
- Auto-install of GitDoc, Markdown All in One, Markdown for Humans
- Git init and initial commit on workspace creation
