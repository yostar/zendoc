# LinkedIn Post: Zendoc Launch

---

I've been puzzled by something for a while.

Software development has incredible tools—version control, AI assistants, instant sync, workspaces that just work. But when I sit down to write a document, a proposal, or a novel, none of that exists. I'm back to "Save As" and hoping I don't lose anything.

Why? Why do we give developers industrial-grade infrastructure and leave everyone else with tools from 2005?

So I built something.

**Zendoc** is a writing environment that runs inside Cursor. Two clicks to set up. Your work auto-commits to GitHub. AI that acts like a librarian, not a coder. No walled gardens, no proprietary formats—just Markdown files you own.

It's open source. It's free. And it's the writing tool I wish had existed years ago.

If you've ever felt that gap—that writing deserves the same care as code—maybe it's for you too.
